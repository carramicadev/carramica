# UI Design System

## Objective

The Carramica UI must follow the official Brand Guideline.

The goal is NOT to recreate the old Bootstrap interface.

Instead, redesign the application into a premium, modern, elegant dashboard that reflects the Carramica brand identity.

The interface must feel:

- Elegant
- Premium
- Clean
- Spacious
- Minimal
- Natural
- Organic
- Timeless

Avoid designs that feel:

- Bootstrap
- Material UI
- AdminLTE
- Template-based
- Overly colorful
- Crowded
- Corporate blue

---

# Design Principles

Every screen must follow these principles.

- Large whitespace
- Soft rounded corners
- Neutral backgrounds
- Natural colors
- Simple layouts
- Clear typography
- Consistent spacing
- Minimal borders

The interface should look like a premium lifestyle brand rather than a traditional ERP system.

# General Rules

Bootstrap must never be used.

Inline CSS must never be used.

All colors must come from this design system.

Do not invent new colors.

Do not invent new typography.

Every page must look like it belongs to the Carramica brand.

When unsure, prioritize simplicity over decoration.

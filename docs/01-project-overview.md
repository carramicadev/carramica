# Project Overview

## Project Name

Carramica

## Objective

Migrate the existing React application into a modern Next.js application.

This migration is not only a framework migration.

It also includes a complete frontend redesign using Tailwind CSS while preserving all existing business logic.

## Goals

- Migrate React → Next.js (App Router)
- Migrate JavaScript → TypeScript
- Replace Bootstrap with Tailwind CSS
- Preserve all business logic
- Preserve Firebase integration
- Improve code maintainability
- Improve SEO
- Improve performance
- Create reusable UI components
- Build a scalable architecture
